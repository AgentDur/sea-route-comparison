# Сравнение морских маршрутов (курсовая работа)

Небольшая программа на Python для сравнения трёх способов определения маршрута между двумя географическими точками:

- ортодромия на сфере (радиус 6371 км);
- локсодромия на той же сфере;
- геодезическая линия на эллипсоиде WGS 84.

Пример взят из курсовой по навигационно-управляющим системам морских объектов (2026). Координаты точек A и B по умолчанию: `(40°, -30°)` и `(50°, -20°)`.

## Быстрый запуск — без команд pip и venv

**Ubuntu / Linux:** распакуйте ZIP, откройте терминал в папке `sea-route-comparison` и выполните:

```bash
bash start.sh
```

**Windows:** распакуйте ZIP и дважды щёлкните `start-windows.bat` (требуется установленный Python 3).

При первом запуске скрипт сам создаст папку `.venv` и установит зависимости из `requirements.txt`; нужен интернет. При последующих запусках пакеты уже установлены. Ничего в системный Python не записывается.

Для других координат на Linux:

```bash
bash start.sh --lat1 40 --lon1 -30 --lat2 50 --lon2 -20
```

Чтобы получить график:

```bash
bash start.sh --plot
```

Если Ubuntu сообщает, что модуль `venv` не установлен, выполните один раз `sudo apt install python3-venv`, затем повторите запуск.

## Ручной запуск (для разработчиков)

Рекомендуется Python 3.10+.

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 route_calc.py
```

На Windows для активации виртуального окружения используйте `.venv\\Scripts\\activate`.

График сравнений можно сохранить так:

```bash
python3 route_calc.py --plot
```

Для других координат:

```bash
python3 route_calc.py --lat1 40 --lon1 -30 --lat2 50 --lon2 -20
```

| Метод | Расстояние, км | Начальный курс / азимут |
| --- | ---: | ---: |
| Ортодромия (сфера) | 1359.255 | 31.81° |
| Локсодромия (сфера) | 1360.122 | 35.16° (постоянный курс) |
| Геодезическая линия WGS 84 | 1359.995 | 31.90° |

Файл `sample_output.txt` содержит реальный вывод программы.

## Что именно вычисляется

Для ортодромии используется формула гаверсинусов и сферическая формула начального курса. Для локсодромии — изометрические широты сферической проекции Меркатора. Для геодезической линии используется метод `Geodesic.WGS84.Inverse` библиотеки GeographicLib (алгоритмы К. Ф. Ф. Карни). **Метод Винсенти в этой программе не реализуется**: он подробно рассмотрен в теоретической части курсовой, а в коде для вычислений на эллипсоиде используется проверенная библиотека.

Получаемые разницы — сравнение расчётных результатов для выбранных моделей, а не утверждение о реальной экономии расстояния между различными моделями поверхности.
